# Application_comptage_piscicole
Ce dossier intègre les scripts et documents relatifs à mon mémoire de Master en "Dynamiques des Écosystèmes Aquatiques", portant sur le développement d'une application via R et Shiny qui permet le traitement semi-automatique des données issues d'un système de vidéocomptage sur la passe à poissons du Pont de la Reine (Hautes-Pyrénées)..
