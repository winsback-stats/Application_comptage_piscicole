# Application_comptage_piscicole
Application R Shiny pour l'exploitation des données de vidéocomptage piscicole : import automatisé, gestion des périodes de panne, analyses annuelles et interannuelles standardisées. Code, jeux de données d'exemple et documentation complète. Passe à poissons de Pont de la Reine (Gave de Pau) — SHEM.
